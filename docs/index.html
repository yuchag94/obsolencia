Panel · Obsolescencia

Salud de tus repositorios, de un vistazo.

Este panel escanea automáticamente los repositorios configurados y muestra, para cada uno, el lenguaje de programación detectado, la versión declarada, si esa versión está próxima a perder soporte oficial (EOL) y las vulnerabilidades abiertas en sus dependencias según la GitHub Advisory Database (el mismo motor que usa Dependabot). Los datos se actualizan automáticamente cada semana mediante GitHub Actions y también pueden refrescarse manualmente. Úsalo como referencia rápida para priorizar actualizaciones de lenguaje y parches de seguridad.
